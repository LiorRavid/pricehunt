# Decision log

A running record of decisions made during the build: what was decided, what else was considered, and why. The significant ones have their own [ADRs](adr/); this log also records the smaller calls. It feeds the README's "Design decisions and trade-offs" section.

| # | Phase | Decision | Alternatives | Reason |
| --- | --- | --- | --- | --- |
| 1 | P0 | .NET SDK **10.0.401** (runtime 10.0.12) and Angular CLI **22.2.0** | .NET 8 or 9 (installed); older Angular | The newest installed LTS SDK and the newest CLI, as the brief requires. .NET 10 brings `TypedResults.ServerSentEvents`, `SseItem<T>.EventId` and built-in minimal-API validation. |
| 2 | P0 | Environment recorded: Node 24.21.0, npm 11.19.0, Git 2.56.0, Windows PowerShell 5.1.26100, Chrome 153 | — | The baseline for the README's prerequisites. PowerShell 7 isn't installed, so the scripts are verified on 5.1 only. |
| 3 | P0 | Build in the existing repository (commit `997bbef` holds the starter) rather than a fresh clone | Clone into a new folder and copy the starter across | It already is the clone of `origin`. Local `main` tracks `origin/main`, so pushes are fast-forwards. |
| 4 | P0 | Move the assignment and the implementation brief into `docs/brief/` | Keep them at the root; stop tracking them | Both were already in the pushed history. Moving them keeps the root in the brief's layout, and the README can link to them. |
| 5 | P0 | Commit locally at each gate, and push once HTTPS access to GitHub works | Change Git's TLS backend (`schannel`) | AVG's HTTPS scanning re-signs GitHub's certificate, which Git's OpenSSL bundle rejects. The repository owner is fixing that themselves. |
| 6 | P0 | Conventional Commits that cite requirement IDs, with no AI co-author trailer | A `Co-Authored-By` trailer | The owner's choice. AI usage is disclosed in the README instead. |
| 7 | P0 | Line endings: `* text=auto eol=lf`, `*.ps1 eol=crlf`, one root `.editorconfig` | Per-project `.editorconfig` files | One source of truth. Windows PowerShell 5.1 expects CRLF, and the global `core.autocrlf=true` must not leak CRLF into the repository. |
| 8 | P0 | Streaming over SSE with `POST` + `fetch` (ADR-001) | SignalR, WebSockets, NDJSON, long polling, gRPC-Web, `EventSource` | One request per search maps a disconnect straight onto cancellation, and validation stays a normal `400`. |
| 9 | P0 | API on fixed HTTP port **5080**, dev server on **4200** with a `/api` proxy | HTTPS dev certificate; CORS | Reviewers need no certificate step and no CORS configuration. |
| 10 | P0 | Dependencies limited to permissively licensed packages; `@axe-core/playwright` (MPL-2.0) is the one exception | Skip automated accessibility checks | The brief requires axe checks. It's a dev-only test dependency and isn't shipped. |
| 11 | P1 | Backend tests run on **Microsoft.Testing.Platform** (`pricehunt-backend/global.json`), with no VSTest packages | VSTest with `xunit.runner.visualstudio` and `Microsoft.NET.Test.Sdk` | xUnit v3 4.x is built on MTP, and the .NET 10 SDK refuses to run it in VSTest mode. Run `dotnet test` from `pricehunt-backend/` so `global.json` is found. |
| 12 | P1 | Coverage with **`coverlet.MTP`** (MIT) | `Microsoft.Testing.Extensions.CodeCoverage`; `coverlet.collector` | The Microsoft extension ships under a proprietary licence, and `coverlet.collector` only works with VSTest. |
| 13 | P1 | Architecture tests with **ArchUnitNET** (`TngTech.ArchUnitNET.xUnitV3`, Apache-2.0) | NetArchTest.Rules | NetArchTest hasn't been released since 2021. ArchUnitNET supports xUnit v3. The framework rules include referenced types (`Types(true)`), and a self-test proves they catch an external dependency instead of passing vacuously. |
| 14 | P1 | Local tool manifest `pricehunt-backend/dotnet-tools.json` (dotnet-ef 10.0.12, ReportGenerator 5.5.11) | Global tools | The brief forbids global installs. In .NET 10, `dotnet new tool-manifest` writes the manifest next to the solution rather than under `.config/`. |
| 15 | P1 | Test methods are exempt from the `Async`-suffix naming rule, and may use underscores (CA1707 off in tests) | `Method_Async` names | Test names read as behaviour sentences, and the test runner is their only caller. The rule still applies to all other code. |
| 16 | P1 | `run.ps1` checks `dotnet --list-sdks` for SDK ≥ 10.0.100, and `-ResetDatabase` deletes `App_Data/pricehunt.db*` | A `global.json` SDK pin | This gives a clear failure message on machines without the SDK (verified with `dotnet` removed from PATH), and doesn't block newer SDKs. |
| 17 | P2 | The orchestrator is a thin `IAsyncEnumerable` iterator over an internal `SearchRun` whose ordinary async methods hold every try/catch; completions come from `Task.WhenEach` | `Channel<T>` producer and consumer | This sidesteps the no-`yield`-inside-`try`/`catch` rule without a second concurrency primitive. On .NET 9 and later, `Task.WhenEach` gives completion order directly. |
| 18 | P2 | A search where every supplier answered is `Completed`, even if a token fired at that moment. Otherwise the status comes from which token fired (caller → `Cancelled`, deadline → `TimedOut`) | Always trust the token | The recorded status should describe what happened to the suppliers, not a race with the timer. |
| 19 | P2 | Response writes and finalisation use their own short timeout (`Search:PersistenceTimeout`), never the request token | Request token for per-response writes | A response that has already arrived must still be recorded if the client disconnects mid-write (DB2). |
| 20 | P2 | Supplier calls go through `WaitAsync(token)`, and abandoned calls get a continuation that observes their exceptions | Trust suppliers to honour cancellation | The 6-second guarantee (SV3) must not depend on supplier cooperation. A mutation check confirms the test catches its removal. |
| 21 | P2 | Hand-written `TaskCompletionSource` fakes and `FakeTimeProvider`, no mocking library | NSubstitute | The fakes decide exactly when each supplier answers. Tests await signals and never sleep. 15 consecutive runs were green. |
| 22 | P2 | Coverage thresholds are enforced per layer with `coverlet.MTP --coverlet-threshold` (Domain and Application ≥ 90, whole numbers only); ReportGenerator produces the merged report | ReportGenerator thresholds | ReportGenerator 5.5.11 has no threshold option. A per-layer check also shows that each layer's own tests cover it. |
| 23 | P2 | `SupplierException` has only the constructor it needs | The "standard" exception constructors | CA1032 isn't part of this analysis level, and unused constructors were dead code. |
| 24 | P3 | Seven suppliers are **configured instances of three behaviour classes** (Reliable, Flaky, Unresponsive), with invented names (Albatross Freight … Gullwing Transport) | Seven hand-written classes | The behaviours differ, not the suppliers. The configuration shows at a glance which one is flaky and which is silent, and a test checks the shipped file (S1–S4). |
| 25 | P3 | One seeded `Random` per supplier (seed combined with the supplier's position), behind a lock | One shared `Random` | Reproducible per supplier however the calls interleave. `Random` isn't thread-safe. |
| 26 | P3 | Database improvements over the brief's shape: a `Suppliers` table, normalised origin and destination columns, and a unique index on (search, supplier) (ADR-003) | Exactly the brief's three tables | Gives FK integrity, supplier sorting by name, Unicode-correct case-insensitive matching (SQLite `NOCASE` is ASCII-only), and one outcome per supplier enforced in the database. |
| 27 | P3 | Persistence entities with explicit mapping, an `internal` `DbContext` and `IDbContextFactory` | EF-mapped domain classes; a scoped `DbContext` | Keeps the Domain free of EF, keeps the API away from the database, and gives each write a short-lived context. |
| 28 | P3 | Database file at `pricehunt-backend/src/PriceHunt.Api/App_Data/pricehunt.db` (`Database:Path`, relative to the content root), git-ignored; WAL mode | A per-user folder; the shell's working directory | The location is deterministic whatever folder `run.ps1` is started from, easy to find, and reset with `-ResetDatabase`. |
| 29 | P3 | Tests use real SQLite temp files (per test, or one per class for the read-only history dataset); connection pools are cleared before deletion | EF InMemory; shared in-memory connection | Real SQL translation, constraints, migrations and WAL. 10 consecutive runs were green with no leftover files. |
| 30 | P3 | The history location filter is a case-insensitive substring match | Exact match | A filter text box should find "Haifa Port" when you type "haifa". |
| 31 | P4 | Search requests are validated in one place, the Application's `SearchPlanner`, returning `TypedResults.ValidationProblem` before streaming; no DataAnnotations and no `AddValidation()` | .NET 10 built-in minimal-API validation or FluentValidation alongside the planner | A live probe showed the DataAnnotations weren't being enforced: the planner's messages came back. Two validators would also word the same rule differently. The planner already reports every field error at once, with the messages the client mirrors. |
| 32 | P4 | Every history rule lives in `HistoryQueryParameters.TryCreateFilter`: sort whitelist, direction, page bounds, the 100-item size cap, date order and supplier-id format. Defaults are `sortBy=date`, `sortDirection=desc`, `pageSize=20` | Enum binding plus attributes | One visible list of rules, camelCase field errors, and case-insensitive values (`sortBy=PRICE`). An unknown but well-formed supplier id simply matches nothing. |
| 33 | P4 | SSE payloads are polymorphic records with `[JsonDerivedType]` and no discriminator (the SSE `event:` field carries the type); enums are strings; timestamps are UTC `Z`; durations are integer `…Ms` | A `$type` discriminator; `SseItem<object>` | The event name already identifies the payload. The typed records document the contract. |
| 34 | P4 | The abort test runs on `TestServer`, and the API tests await a repository-decorator signal | Real Kestrel via `UseKestrel()`; polling | TestServer does pass the client's disconnect on as `RequestAborted` (verified). Signals keep the tests free of sleeps; the API suite was green 10 times in a row. |
